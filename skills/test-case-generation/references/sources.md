# Research references

Reviewed 2026-11-18. Use these as test-design references, not evidence about an uninspected repository.
Match the target project's assertion library and fixture style.

- [Gerard Meszaros — xUnit Test Patterns (Test Oracles & Fresh Fixtures)](http://xunitpatterns.com/): Independent result verification, fresh per-test fixtures, and avoiding fragile overspecified mocks.
- [Cem Kaner, James Bach & Bret Pettichord — Boundary Value & Equivalence Partitioning](https://kaner.com/): Selecting minimal input partitions that expose off-by-one and domain-boundary defects.
