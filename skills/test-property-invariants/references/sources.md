# Research references

Reviewed 2026-11-18. Use these as property-design references, not evidence about an uninspected repository.
Use stdlib seeded generators unless a property-testing library is already declared in repository dependencies.

- [Koen Claessen & John Hughes — QuickCheck: A Lightweight Tool for Random Testing](https://dl.acm.org/doi/10.1145/351240.351266): Algebraic invariants, structured generators, and shrinking counterexamples.
- [Tsong Yueh Chen et al. — Metamorphic Testing: A New Approach for Generating Next Test Cases](https://arxiv.org/abs/2002.12543): Verifying input-transformation relations when exact point-wise test oracles are unavailable.
