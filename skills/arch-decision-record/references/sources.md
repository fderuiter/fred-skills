# Research references

Reviewed 2026-11-18. Use these as decision-recording methods, not evidence about an uninspected repository.
Verify repository conventions and licensing before adopting external templates.

- [Michael Nygard — Documenting Architecture Decisions](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions): Lightweight ADR structure covering context, decision, status, and consequences.
- [MADR — Markdown Architectural Decision Records](https://adr.github.io/madr/): Structured comparison of decision drivers, considered options, and pros/cons.
