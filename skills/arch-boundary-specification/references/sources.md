# Research references

Reviewed 2026-11-18. Use these as boundary-modeling methods, not evidence about an uninspected repository.
Verify framework behavior and project conventions before applying patterns.

- [C4 Model — Context, Containers, Components](https://c4model.com/): Hierarchical boundary notation separating system, deployable service, and module scopes.
- [OWASP Threat Modeling Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Threat_Modeling_Cheat_Sheet.html): Trust boundary identification across data-flow transitions and privilege changes.
