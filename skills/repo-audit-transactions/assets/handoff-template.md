# Audit handoff

- Run ID, protocol/schema version, repository, revision/content snapshot, dirty state.
- Requested topic and subsystem scope; inspected/partial/not-reviewed/not-applicable coverage.
- Artifact locations; contract/evidence/finding IDs owned or imported.
- Existing safeguards and refuted candidates to avoid rediscovery.
- Confirmed versus supported versus needs-validation findings and unresolved preconditions.
- Checks actually executed with commands/results; proposed or blocked checks.
- Existing issue lookup state and verified links; draft versus published state.
- Next concrete action, dependencies, expected output, and explicit mutation scope.

Revalidate affected records if the snapshot changed. Preserve unrelated run records.
