# Research references

Reviewed 2026-11-18. Use these as feedback-synthesis guidelines, not evidence about an uninspected diff.
Respect repository-specific review norms and severity definitions.

- [Google Engineering Practices — How to Write Code Review Comments](https://google.github.io/eng-practices/review/reviewer/comments.html): Distinguishing blocking defects from optional nitpicks and writing actionable rationale.
- [Conventional Comments Specification](https://conventionalcomments.org/): Clear intent labels separating blocking issues, questions, and non-blocking suggestions.
