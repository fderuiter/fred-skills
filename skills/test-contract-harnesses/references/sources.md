# Research references

Reviewed 2026-11-18. Use these as contract-testing methods, not evidence about an uninspected repository.
Prefer dependencies already installed in the repository before suggesting external frameworks.

- [Martin Fowler — ContractTest & Verified Test Doubles](https://martinfowler.com/bliki/ContractTest.html): Preventing drift between test doubles, consumer expectations, and real provider behavior.
- [JSON Schema Specification (Draft 2020-12)](https://json-schema.org/specification): Deterministic structural and boundary validation for wire payloads.
