# Research references

Reviewed 2026-11-18. Use these as invariant-checking methods, not evidence about an uninspected diff.
Confirm language exception and transaction semantics in the target runtime.

- [Bertrand Meyer — Applying "Design by Contract"](https://se.inf.ethz.ch/~meyer/publications/computer/contract.pdf): Preconditions, postconditions, and class invariants across state transitions.
- [David Abrahams — Exception-Safety in Generic Components](https://www.boost.org/community/exception_safety.html): Basic, strong (commit-or-rollback), and no-throw exception-safety guarantees.
