# Research references

Reviewed 2026-11-18. Use these as test-verification references, not evidence about an uninspected repository.
Check the installed test runner flags before running commands.

- [pytest Documentation — Exit Codes, Collection & Skip/XFail Reporting](https://docs.pytest.org/en/stable/reference/exit-codes.html): Distinguishing zero-collected runs (`exit 5`) and skipped tests (`-rs`) from executed passes.
- [Christopher Wright et al. — Mutation Testing in Practice](https://dl.acm.org/doi/10.1145/3377811.3380380): Evaluating whether passing test suites actually detect behavioral regressions.
