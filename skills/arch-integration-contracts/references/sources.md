# Research references

Reviewed 2026-11-18. Use these as wire-contract engineering references, not evidence about an uninspected repository.
Check protocol versions and serializer defaults in the target stack before applying rules.

- [Protocol Buffers Language Guide — Updating A Message Type](https://protobuf.dev/programming-guides/proto3/#updating): Wire-safe field numbering, unknown-field preservation, and enum compatibility rules.
- [IETF RFC 9110 — HTTP Semantics (Idempotent Methods & Status Codes)](https://www.rfc-editor.org/rfc/rfc9110): Standard HTTP method idempotency and retryable vs client-error semantics.
