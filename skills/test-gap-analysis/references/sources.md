# Research references

Reviewed 2026-11-18. Use these as test-adequacy evaluation concepts, not evidence about an uninspected repository.
Check the repository's installed test runner and conventions before proposing tooling.

- [Google Testing Blog — Code Coverage Best Practices](https://testing.googleblog.com/2020/08/code-coverage-best-practices.html): Why behavioral assertion quality and uncovered error branches matter more than raw coverage targets.
- [Yue Jia & Mark Harman — An Analysis and Survey of the Development of Mutation Testing](https://ieeexplore.ieee.org/document/5487526): Fault-revealing oracle strength versus assertion-free execution.
